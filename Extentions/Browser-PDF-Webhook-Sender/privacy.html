Browser PDF Webhook Sender Privacy Policy

Publisher: UGomez
Effective date: October 2, 2026
Contact: Janiel@gomezagency.net

Purpose

This policy describes the Chrome Web Store build of Browser PDF Webhook Sender, version 0.25.37. The extension supports UGomez's internal quote-document workflow. It captures readable PDFs from browser tabs and supported quote pages and delivers them to Quote-to-Email or a configured HTTPS webhook when the user initiates a send action. It has no billing integration or payment-collection feature.

Information the extension handles

  • PDF document contents and filenames. Documents can contain personal, insurance or other confidential information depending on the files the user opens. The extension does not collect payment details through payment forms or payment systems, and it does not filter or redact the contents of the PDFs it forwards.
  • Relevant source-page URLs, page titles, PDF URLs, capture timestamps and delivery metadata. JSON webhook mode also includes the browser's user-agent string.
  • Delivery preferences, webhook and configuration URLs, optional configuration authentication tokens, and cached administrator JSON settings.
  • Temporary PDF request bodies and headers needed to replay authenticated Farmers PolicyCenter document requests using the existing site session.
  • Local diagnostic events used to investigate PDF capture and delivery problems. Some events include relevant document/page metadata.

Background capture and manual delivery

The extension can detect and cache PDFs before the user sends them. On supported quote pages it observes document triggers and relevant requests, and it can detect readable PDF downloads. PDF detection alone does not upload a document to Quote-to-Email or the webhook.

The toolbar button and extension send controls initiate document delivery. Depending on the chosen mode, the extension hands the PDF to the signed-in Quote-to-Email dashboard, posts it to the configured webhook, or does both.

Storage

PDF bodies are cached locally in the extension's IndexedDB database. PDF metadata and diagnostics use local extension storage. Cached PDFs can be replaced by subsequent captures and cleared through the extension's controls; tab-specific caches are cleared when the source tab closes. This is not a promise that all local records expire at a fixed time.

Delivery settings, optional administrator configuration and the optional configuration bearer token use Chrome sync storage. When browser synchronization is enabled, Google may synchronize those settings according to the user's Chrome settings. Pending Quote-to-Email handoffs use session storage and are removed after the dashboard acknowledges delivery, after 15 minutes if not delivered, or when their target tab closes. The extension's dashboard bridge also holds document data in page memory to support downloading a sent PDF; this memory is cleared when the page unloads.

Temporary authenticated PDF replay information is held in service-worker memory for the capture workflow. Removing the extension removes its local extension storage; recipient services may retain documents already delivered to them.

Destinations and sharing

Quote-to-Email delivery hands the PDF to quote-to-email.giatools.com. Webhook delivery sends PDF contents and relevant metadata to the endpoint in the effective configuration. Optional administrator configuration can override the destination and delivery mode.

If remote configuration is enabled, the extension requests JSON from the configured HTTPS server before sending and periodically, normally every 30 minutes. An optional bearer token is included in requests to that server. Remote configuration is treated as data; the extension does not execute JavaScript received from it.

The extension package contains no advertising or analytics integration. Data is still transferred to the selected document destination, the configuration server when enabled, and Chrome's synchronization service when applicable.

Recipient service practices

In UGomez's intended Quote-to-Email workflow, the PDF is made available to the person currently using the extension, is temporarily cached, can be downloaded, and is automatically cleared from the cache. This policy does not promise a fixed cache lifetime for the receiving application. The 15-minute limit above applies to the extension's undelivered handoff queue, not all copies held by the application.

A downloaded PDF is a separate file controlled by the user. Automatically clearing a cache does not delete downloaded copies. A separately configured webhook is controlled by its operator and may retain delivered documents according to that operator's practices. Contact UGomez for assistance with the internal workflow, or the relevant operator for a separate webhook.

Security and user choices

This store build requires HTTPS webhook and remote-configuration URLs and rejects HTTP destinations. Users can change delivery settings, clear cached PDFs through the extension controls, disable optional administrator configuration by removing its URL, disable or uninstall the extension, and choose whether Chrome permits access to local file URLs.

Broad host access supports PDFs from arbitrary websites and user-configured destinations. Automatically declared content scripts are limited to the supported Farmers PolicyCenter, Aegis and Quote-to-Email hosts. Users should send only documents they are authorized to share.

Limited use of data

UGomez's use of data handled by this extension complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. User data is used to provide or improve the disclosed PDF capture and delivery workflow, including related security and reliability operations.

UGomez does not sell or transfer user data outside the approved Limited Use cases, does not use or transfer user data for purposes unrelated to the extension's single purpose, and does not use or transfer user data to determine creditworthiness or for lending purposes. User data is not used for personalized, retargeted or interest-based advertising, or transferred to advertising platforms, data brokers or information resellers.

The PDF is made available to the user for the requested workflow. UGomez does not otherwise allow people to read user data except with the user's explicit consent for specific data, when necessary for security or legal compliance, or when data is aggregated and anonymized for internal operations as permitted by the Limited Use requirements.

Requests and contact

For privacy questions, correction or deletion requests, contact UGomez at Janiel@gomezagency.net. Requests concerning documents already sent to a separate webhook operator may also need to be directed to that operator.
